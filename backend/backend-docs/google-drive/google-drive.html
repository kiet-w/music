Google Drive Module

Module xử lý các nghiệp vụ liên quan đến việc kết nối, xác thực OAuth2 và tương tác với Google Drive, hỗ trợ liệt kê và import nhạc MP3 trực tiếp từ Drive vào hệ thống ứng dụng.

1. Tổng quan Kiến trúc (Component Overview)

Module GoogleDrive chịu trách nhiệm xử lý các nghiệp vụ liên quan đến việc kết nối và thao tác với Google Drive của người dùng. Bao gồm: cung cấp URL xác thực OAuth2, trao đổi mã code lấy token, kiểm tra trạng thái kết nối, liệt kê danh sách file nhạc (.mp3) trong Drive, và import (tải về) file từ Google Drive vào hệ thống lưu trữ của ứng dụng. Module này cũng cho phép tạo hoặc liên kết với Album khi import bài hát.

2. Các Dependencies (Dependencies Injection)

  • PrismaService: Tương tác Database (bảng User).
  • CACHE_MANAGER (Cache): Lưu bộ nhớ đệm (cache) cho trạng thái OAuth và kết nối.
  • StorageService: Dịch vụ xử lý tải và lưu file vật lý/cloud.
  • SongRepository: Giao tiếp với database lưu thông tin bài hát.
  • AlbumService & AlbumRepository: Xử lý logic tìm hoặc tạo album.
  • PinoLogger: Ghi log hệ thống.

4. Phân tích chi tiết Controller & Service

GoogleDriveController

  • ping(): GET /google-drive/ping. Trả về trạng thái, thời gian, version.
  • getStatus(user): GET /google-drive/status. Trả về { connected: boolean }. Dùng cache.
  • getAuthUrl(user): GET /google-drive/auth-url. Gọi service lấy URL OAuth2 của Google.
  • exchangeCode(user, dto): POST /google-drive/exchange-code. Nhận code và state.
  • listFiles(user): GET /google-drive/files. Liệt kê các file âm thanh và shortcut.
  • importFile(user, importDto): POST /google-drive/import. Tải file và lưu vào hệ thống.

GoogleDriveService

  • generateAuthUrl(userId): Sinh UUID cho state, lưu vào cache, gọi oauth2Client.generateAuthUrl().
  • isConnected(userId): Kiểm tra trường googleRefreshToken trong bảng User.
  • exchangeCodeForTokens(userId, code, state): Validate state chống CSRF, đổi code lấy tokens.
  • importFile(userId, importDto): Tải mp3 dạng stream, sanitize name, upload qua StorageService, lưu DB.
  • listFiles(userId): Gọi drive.files.list() với filter cho audio và shortcut.

5. Pattern quan trọng & Đánh giá

OAuth2 State Caching (Chống CSRF)

const state = randomUUID();
await this.cacheManager.set(`google_auth_state:${state}`, userId, 300000);
// Sau đó kiểm tra lại lúc callback

Tránh CSRF Attack trong quá trình callback OAuth mà không cần lưu vào Database dài hạn.

Stream Piping

const res = await drive.files.get({ fileId, alt: 'media'}, { responseType: 'stream' });
await this.storageService.uploadStream(res.data, ...);

Truyền thẳng stream từ Google SDK sang Storage Service, tránh tốn RAM khi file nhạc lớn.

Đánh giá (Cần cải thiện)

  • Chưa có Transaction cho Import: Quá trình upload Storage và create DB độc lập. Nếu create DB xịt, có thể gây orphan file trên Storage.
  • Hardcode Error Messages & MimeTypes: Cần tách riêng vào constant file.
